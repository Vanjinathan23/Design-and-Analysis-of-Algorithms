# Algorithms Programs

This folder contains separate Python programs for all 14 questions from the supplied assignment.

## Files

1. `01_list_test_cases.py` - List sorting test cases
2. `02_selection_sort.py` - Selection Sort
3. `03_optimized_bubble_sort.py` - Optimized Bubble Sort
4. `04_insertion_sort_duplicates.py` - Insertion Sort with duplicates
5. `05_kth_missing_positive.py` - Kth missing positive integer
6. `06_peak_element_binary_search.py` - Peak element in O(log n)
7. `07_find_first_occurrence.py` - First occurrence of a substring
8. `08_substrings_of_another_word.py` - Strings that are substrings of another word
9. `09_closest_pair_brute_force.py` - Closest pair of 2D points
10. `10_convex_hull_brute_force.py` - Convex Hull using brute force
11. `11_convex_hull_given_points.py` - Convex Hull for the supplied point set
12. `12_tsp_exhaustive_search.py` - TSP using exhaustive search
13. `13_assignment_problem_exhaustive.py` - Assignment Problem using exhaustive search
14. `14_knapsack_exhaustive_search.py` - 0-1 Knapsack using exhaustive search

## Run

Python 3 is required.

Example:

```bash
python 02_selection_sort.py
```

All programs use only Python's standard library.
