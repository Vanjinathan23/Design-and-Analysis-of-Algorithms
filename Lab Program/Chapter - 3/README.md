# Algorithms Programs - Set 2

This ZIP contains 16 separate Python programs for the 16 listed problems.

## Programs

01. Maximum and minimum in an array
02. Maximum and minimum in a sorted array
03. Merge Sort
04. Merge Sort with comparison counting
05. Quick Sort using the first element as pivot
06. Quick Sort using the middle element as pivot
07. Binary Search with comparison counting
08. Binary Search with midpoint/step display
09. K closest points to the origin
10. Four Sum II tuple count
11. Median of Medians
12. Median of Medians function
13. Meet in the Middle - closest subset sum
14. Meet in the Middle - exact subset sum
15. Strassen's 2x2 matrix multiplication
16. Karatsuba multiplication

## Run

Python 3 is required.

Example:
python 03_merge_sort.py

All programs use only the Python standard library.
